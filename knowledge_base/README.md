# Lafia Public Transportation Knowledge Base

## Purpose and scope

This knowledge base contains sourced information for the RAG-powered Public
Transportation Information Assistant. Its geographical scope is Lafia,
Nasarawa State, Nigeria, and relevant intercity connections to and from Lafia.

## Evidence categories

- **Verified** records contain information supported by identified operator or
  government publications. A source supports only what it explicitly states;
  it does not automatically establish current operations, schedules, or fares.
- **Historical** records preserve dated reporting or observations that must not
  be presented as current facts.
- **Unverified** records are leads for further research, not confirmation of a
  current location, route, stand, or operator.
- **Mixed** records combine more than one evidence category or provenance,
  such as operator-published observations with government-referenced
  information, or current observations with historical reports. Each claim's
  status and limitations must be stated where it appears.

The `documentation_policy` status identifies this guidance file, not a
transport evidence record. A `source_register` status identifies the source
index; neither status is a substitute for the evidence status of a factual
record. Records using a mixed status must identify the category of each claim.

Synthetic information must never be used to answer real passenger questions.
Synthetic test material, if maintained elsewhere for testing, must be clearly
separated from this knowledge base.

Fares, routes, schedules, and movement restrictions can change and require
periodic review. Every record should retain its source, publication date,
verification status, and last-reviewed date. If an exact source URL was not
captured, record that fact rather than supplying an inferred URL.
